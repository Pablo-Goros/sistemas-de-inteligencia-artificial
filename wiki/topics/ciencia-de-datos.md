# Ciencia de datos

## Overview

La ciencia de datos reúne generación, almacenamiento, curado, análisis, modelado, gobierno y uso de datos para producir conocimiento y apoyar decisiones. El apunte la presenta como un área conectada con estadística, ingeniería de datos, Machine Learning, MLOps y análisis de dominio. [OFF-001, pp. 203-205]

## Core concepts

- El curado puede incluir consultas, extracción y estandarización; el análisis exploratorio de datos (EDA) busca comprender estructura estadística y contexto mediante transformaciones y visualizaciones. [OFF-001, p. 205]
- La calidad y representatividad de los datos limitan el desempeño de cualquier modelo: garbage in, garbage out. El apunte también advierte sobre survivorship bias, sampling bias y falsa causalidad. [OFF-001, pp. 205-207]
- Optimizar un indicador puede generar consecuencias contrarias al objetivo real si el indicador no representa adecuadamente el problema. [OFF-001, p. 206]
- La frontera digital representa las actividades automatizadas; empujar esa frontera es una fuente de innovación y puede producir capacidades superhumanas en tareas específicas. [OFF-001, pp. 207-208]

## Relationships

La ciencia de datos prepara y contextualiza los datos que consume el [aprendizaje automático](aprendizaje-automatico.md). La [evaluación de modelos](evaluacion-de-modelos.md) debe considerar sesgos, balance de clases y el contexto de la decisión, no solo una métrica.

## Exam relevance

Se debe poder explicar EDA, curado de datos, garbage in/garbage out y sesgos de supervivencia, muestreo y causalidad; el material oficial los trata como advertencias prácticas. [OFF-001, pp. 203-208]
